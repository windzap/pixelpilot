Privacy Policy

Last updated: 12 November 2026

This policy explains how PixelPilot ("the app") accesses, uses, stores and shares Google user data.

Google user data the app accesses

With the user's permission (Google OAuth scope https://www.googleapis.com/auth/adwords), the app calls the Google Ads API on the user's own Google Ads accounts. It only reads keyword planning data: keyword ideas, average monthly searches, competition and top-of-page bid ranges.

How the data is used

The data is used only to produce keyword and SEO opportunity reports for the user. The app does not create, edit or delete campaigns, ads, budgets or settings, and does not read billing or payment information.

How the data is stored

The OAuth refresh token and keyword results are stored only on the user's own computer, in files readable only by that user. Keyword results are cached for up to 30 days and then deleted. No data is stored on any external server.

Sharing

Google user data is not sold, shared with or transferred to third parties, and is not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Users can revoke the app's access at any time at myaccount.google.com/permissions, and can ask for local data to be deleted by emailing the contact below.
