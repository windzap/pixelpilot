# pixelpilot.my

Static site served by GitHub Pages (custom domain in `CNAME`).

```
/
├── index.html            Homepage
├── privacy.html          Privacy policy (needed for Google Ads API access; keep the wording)
├── CNAME                 pixelpilot.my
├── robots.txt
├── sitemap.xml
├── 404.html              Not-found page (noindex)
├── .nojekyll             Serve files as-is (no Jekyll build)
└── assets/
    ├── css/style.css     All styles (brand colours and fonts at the top)
    ├── js/main.js        Word animations (respects reduced motion)
    ├── img/brand/        Logos (PNG from the PixelPilot brand pack; never retype the logo)
    ├── img/social/       Share image (1200×630) for WhatsApp, Facebook, LinkedIn
    └── icons/            Favicon and Apple touch icon
```

Brand: orange #F05A2A · charcoal #202020 · stone #D2CEC4 · warm paper #F5F0E7.
Fonts: Bricolage Grotesque (headings), Work Sans (body), Geist Mono (labels).
